# Fanique design comparison

Informational website redesign prototype for reviewing the current Fanique page against a more coherent product and buyer-planning layout.

The page contains six product-family cards, local filtering, a product-aware project outline, four planning guides, two local calculators and empty CSV worksheets. It sends no enquiries and processes no orders or payments. There are no analytics, external font requests or paid services. Search robots are asked not to index this comparison site.

Product images are optimized derivatives of images published on the current Fanique website and are used for this user-requested redesign comparison. Product-family labels are not independently verified manufacturing specifications. No prices, minimum quantities or lead times are invented. The visual mark is a concept for this preview.

The calculators preserve the existing locally reviewed calculation/export logic. They support planning rather than approving artwork or proving delivered cost. There has been no new browser visual or device-level test of this published page; the validation record describes the checks actually performed.

Open `index.html` for the full English preview and `comparison.html` for the Chinese explanation. GitHub Pages is used to publish this informational comparison prototype; it does not replace the production website at getfanique.com.
