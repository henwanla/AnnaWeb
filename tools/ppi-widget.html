Pixel density alone does not approve artwork for production. Check actual detail, cropping, colour, template, material, print process and sample approval.

Calculation method

Width PPI = used pixel width ÷ final width in inches. Calculate height separately. One inch is 2.54 cm or 25.4 mm.

Recalculate after cropping or resizing the placed object. Changing resolution metadata or adding interpolated pixels does not establish original detail.

Use pixels and physical dimensions for the same image area. If a frame only clips an image without resampling or changing its scale, do not divide the full source-image pixel count by the smaller clipped frame width.
